---
title: Build and edit playlists
description: Curate named playlists for the iPod (and Plex/Apple Music).
---

Playlists are named, saved collections stored in clickwheel's catalog. They show
up under Music → Playlists on the iPod once synced.

## Create and edit

```bash
clickwheel playlist                 # list saved playlists
clickwheel edit                     # interactive: add/remove artists or songs, set description
clickwheel edit --add "Nirvana"   # non-interactive (scriptable)
clickwheel edit --remove "Beastie Boys"
clickwheel delete <name>            # delete a playlist (with confirmation)
```

You can edit by **artist** or by **individual song**. The interactive editor
offers "Add songs" / "Remove songs" (search, then check the tracks you want).
The same is scriptable with track paths:

```bash
clickwheel edit "road trip" --add-track "/Volumes/Music/Nirvana/Nevermind/02 In Bloom.m4a"
clickwheel edit "road trip" --remove-track "/Volumes/Music/Beastie Boys/Ill Communication/01 Sure Shot.mp3"
```

## Put a playlist on the iPod

```bash
clickwheel sync   # syncs your selected playlist to the device
```

See [Sync to iPod](/guides/sync-to-ipod) for the full flow.

## Two concepts, don't conflate them

- **Adding music to the device**: you just want tracks browsable by
  artist/album. No named playlist needed.
- **A curated playlist**: a named collection that appears under Music →
  Playlists on the iPod.

The same playlists can also be pushed to [Plex/Plexamp](/guides/plex) and
[Apple Music](/guides/apple-music).
