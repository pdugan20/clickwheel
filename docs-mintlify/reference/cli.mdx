clickwheel's commands, grouped by what they touch. Run `clickwheel --help` (or
`clickwheel <command> --help`) for the same information in your terminal.

<CardGroup cols={2}>
  <Card title="Library" href="/reference/cli/library">
    Index and repair your library: `scan`, `fix`.
  </Card>
  <Card title="Playlists" href="/reference/cli/playlists">
    Build and manage saved playlists: `playlist`, `edit`, `delete`, `heal`.
  </Card>
  <Card title="iPod" href="/reference/cli/ipod">
    Load and sync the device: `select`, `diff`, `sync`, `ls`, `eject`.
  </Card>
  <Card title="Plex" href="/reference/cli/plex">
    Push and pull Plex playlists: `plex doctor/list/pull`, `sync-plex`.
  </Card>
  <Card title="Apple Music" href="/reference/cli/apple-music">
    Sync with Apple Music: `apple auth/doctor/match/push/list/pull/delete`.
  </Card>
  <Card title="Last.fm" href="/reference/cli/lastfm">
    Scrobble your iPod listens: `scrobble`.
  </Card>
</CardGroup>
